Web Programming Studio: a learning journey, not a race to the project

I'd like to redesign COSC3060 and its Canvas shell so students engage, practise and create more in studio mode. The main problem I want to solve: many students lean on AI tools to finish the group project without mastering the fundamentals.

  • Fundamentals before the project
  • Practice for the AI era
  • Fairer group work
  • Schedule matches assessment
  • Stronger self-regulated learning
Tuan · RMIT University Vietnam, SGS · ideas for our Canvas meeting, November 2026

Every topic walks the same four steps

The journey follows Bloom's taxonomy. Every topic reaches at least apply; the higher levels come through the group project. Weekly topics are named by what students can do, such as "Structure a page" or "Build a server", with two topics a week, one per session.

What one session looks like

Each 3-hour session follows the same rhythm, so students always know what comes next and can plan their own study around it.

4 hpre-class preparation a week
6 hin class, two 3-hour sessions
6 hself-regulated learning after class

    How I picture it in Canvas

    One module per week, and inside it the same set of items for each session. Students should be able to see at a glance where they are on the journey.

      Assessment changes

      The session-opening quizzes use source code and are graded on completion. Their 5% comes out of Assessment 1, which drops to 15%. The individual full-stack lab test stays at 40%, as it is.
